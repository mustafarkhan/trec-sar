First public release of TREC-SAR — the civilian search-and-rescue successor to TREC, a tracked, reconfigurable UGV built for the Pakistan Army (demonstrated to the Commander, 11 Corps; prototype delivered to 212 Brigade for field trials).

**What's in it**
- `trecsar` command-line tool and Python API: run, compare and benchmark search planners
- Link-aware search planner: chooses search goals, radio-relay placement and planned link-loss windows from a Bayesian probability map
- Three built-in scenarios (winter forest, tunnel after a rock fall, industrial chemical release) plus **custom sites from a PNG map + YAML**
- Held-out benchmark: 4,000 simulated missions with 95 % confidence intervals and an ablation study
- ROS 2 Jazzy stack: URDF, Gazebo Harmonic worlds, mission manager, radio-link simulator, detectors, SLAM + Nav2 bringup, and a headless mode
- CI: lint, tests on Python 3.10–3.13, ROS 2 build, and an end-to-end headless mission that must deliver a casualty report

**Headline result (simulation):** in the winter forest, link-aware planning raises the share of missions where the command post receives the casualty report from 36–42 % to 60 %, using about half the relays.

**Install**
```bash
git clone https://github.com/mustafarkhan/trec-sar.git && cd trec-sar
pip install -e "core[viz]"
trecsar compare --scenario tunnel --seed 1003
```

All results are simulation; see `docs/FAILURE_MODES.md` for assumptions and limits. Not certified for operational use.
